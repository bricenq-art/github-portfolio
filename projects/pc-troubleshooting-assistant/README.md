# PC Troubleshooting Assistant

**Author:** Bricen Quebedeaux  
**Course:** COSC 4272 Senior Seminar  
**Stack:** HTML, CSS, vanilla JavaScript  
**Demo:** [Launch on GitHub Pages](https://bricenq-art.github.io/github-portfolio/projects/pc-troubleshooting-assistant/)

## Overview
A browser-based interactive guide for six common PC support scenarios: network, performance, application crashes, display, audio, and storage. Users choose a category or describe a problem; a transparent keyword matcher selects a predefined checklist. The tool provides safe starting steps and escalation advice.

## Run
Open `index.html` in a browser, or visit the hosted demo. No dependencies, credentials, or server required.

## Features
- Responsive and keyboard-accessible form
- Description-based keyword matching or manual category selection
- Six step-by-step troubleshooting checklists
- Copy checklist and print options
- No personal data sent to a server

## How it works
`app.js` stores six troubleshooting guides. If a category is manually selected, it is used. Otherwise the program counts matching keywords in the user's description and chooses the category with the highest score. No match yields a request for more information. Recommendations are rule-based, **not generated by a live AI model**.

## AI-assisted development disclosure
ChatGPT was used to draft and structure the initial HTML, CSS, JavaScript, troubleshooting categories, and documentation. The application itself does not call an AI API. This distinction should be clear in the submission. The student should run, test, review, and document any changes before claiming verified functionality.

- [ ] Type `My app crashes` and verify crash guide
- [ ] Type unrelated words and verify no-match message
- [ ] Submit an empty description in automatic mode and verify validation
- [ ] Test reset, copy, and print
- [ ] Test mobile viewport and keyboard navigation
- [ ] Capture screenshots in `../../screenshots/`

## Limitations and future work
Keyword matching may misclassify ambiguous issues. Advice is general and not a replacement for professional diagnostics. Future improvements could include feedback, device-specific guides, and a properly secured AI-backed API (never place secret API keys in GitHub Pages code).
