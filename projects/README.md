## Project 1: PC Troubleshooting Assistant

**Technologies:** HTML, CSS, JavaScript, AI-Assisted Development

### Description

The PC Troubleshooting Assistant is a browser-based application developed for my COSC 4272 Senior Seminar project. Its purpose is to help users identify common computer problems and receive basic troubleshooting recommendations.

The application uses keyword-based logic to recognize issues related to computer performance, internet connectivity, software crashes, display problems, audio issues, and storage.

### Features

- Accepts user descriptions of computer problems.
- Identifies common troubleshooting categories.
- Provides suggested steps to resolve technical issues.
- Runs directly in a web browser without requiring additional software.
- Uses a simple interface designed to be accessible to users with different levels of technical knowledge.

### Learning Experience

Developing this application helped me practice JavaScript programming, web development, and organizing troubleshooting information into a functional application.

I also gained experience using AI-assisted development tools to help with programming, troubleshooting, and documentation.

**Note:** AI tools assisted the development process. The application itself uses rule-based logic rather than a live AI model.

## Project 3: Custom Command-Line Shell

**Technologies:** C++, Linux, g++, POSIX System Calls

### Description

The Custom Command-Line Shell is a C++ application developed for my COSC 4302 coursework.

The goal of the project was to create a basic command-line interpreter capable of executing commands and interacting with the operating system.

The shell uses Linux system calls such as `fork()`, `execvp()`, and `waitpid()` to create processes, execute external commands, and manage program execution.

### Features

- Displays a custom `my_shell>` command prompt.
- Executes external commands such as `ls`, `pwd`, and `echo`.
- Supports directory navigation using `cd`.
- Allows users to exit the application using `exit`.
- Reads the contents of `readme.txt` using the `readme` command.
- Appends text to files using the `write` command.
- Includes basic error handling for invalid commands and file operations.

### Learning Experience

Developing this project helped me better understand how operating systems execute commands and manage processes.

It also strengthened my knowledge of C++, Linux environments, command parsing, and file handling.
