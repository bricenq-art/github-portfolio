# Bricen Quebedeaux — GitHub Portfolio

Professional portfolio for COSC 4272 Senior Seminar, Lamar University. Focus: software development and IT support.

## Website
After GitHub Pages is enabled: https://bricenq-art.github.io/github-portfolio/

## Technology
HTML, CSS, and JavaScript; hosted with GitHub Pages.

## Project status
This is a **starter website**, not a finished submission. The AI application, project code, screenshots, resume PDF, verified contact links, professional photograph, and career documents must be completed before submission.

## Local preview
Open `index.html` in a browser.

## Publishing
1. Upload all files and folders to the `github-portfolio` repository root.
2. Open Settings > Pages. Under Build and deployment choose Deploy from a branch. Select `main` and `/ (root)`; save.
3. Wait for deployment, then visit https://bricenq-art.github.io/github-portfolio/.
